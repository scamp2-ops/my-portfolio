# my-portfolio
My personal portfolio website showcasing my IT skills, projects, and experience.

## Accessibility Improvements

For this project, I worked on making my website easier for everyone to use, including people with disabilities.

### Accessibility Fixes

- **Image Descriptions:** I checked my images to make sure they have accurate alt text so people using screen readers can understand them.
- **Keyboard Accessibility:** I checked that visitors can navigate the website using a keyboard and see which link is selected.
- **Responsive Layout:** I checked my pages at different screen sizes to make sure the content is readable without scrolling sideways.
- **Text Readability:** I checked that text is easy to read against the background colors.
- **Page Structure:** I reviewed my headings and page layout to make the content easier to follow.

### Accessibility Testing

I previously tested my website using WAVE and manually checked keyboard navigation, image descriptions, and mobile responsiveness. I will recheck all three pages after completing the new updates.
